# Strategy prioritization example

Ranks alternatives using a weighted-sum method, runs one-at-a-time sensitivity + seeded Monte Carlo weight perturbation, applies a robustness decision threshold, and emits diagnostics when robustness is insufficient.

## Run
```bash
npm run strategy:rank
```

## Input
- `superintelligence_alignment_options_v0_1.json`

## Output
- `outputs/strategy_prioritization/strategy_ranking_receipt_v0_1.json`
